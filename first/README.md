# Esimesed skriptid

Tunnis õpetajaga koos tehtud skriptid.

* ```first.py``` Esimesed katsetused koodi kirjutamisel faili
* ```for_loop.py``` For-loop tometamised listidega
* ```funktsioonid.py``` Katsetused funktsioonidega
* ```game.py``` Ära arvamise mäng
* ```listid.py``` Kogu informatsioon listidest

Õppimiseks kasuta [Prokeõpikut](https://progeopik.cs.ut.ee/).
